# Serverless REST API Template

Estado: pendiente de implementación. La implementación AyPe se trasladó al repositorio `aype-cafeteria/backend` para mantener separadas la aplicación de negocio y esta plantilla.

## Objetivo

Este repositorio será una plantilla demostrativa de una API REST serverless con FastAPI, documentación OpenAPI/Swagger y persistencia en DynamoDB. Debe permitir configurar nombres de tablas, región, recursos y comportamiento por entorno sin valores ni reglas de negocio propias de una aplicación.

## Alcance actual

La plantilla todavía no contiene una implementación genérica ni infraestructura de despliegue. No debe considerarse lista para uso hasta que se definan el contrato de endpoints, el modelo de datos de ejemplo, la configuración, las pruebas y el despliegue Lambda/API Gateway.
